# Стандарт Строй

Веб-приложение для управленческого учета расходов строительной компании.

## Назначение

Приложение помогает быстро фиксировать операции по объектам, счетам, инвесторам и контрагентам. Это не бухгалтерская система, а рабочий учет для контроля денег, объектов, вложений и текущих расходов.

## Возможности

- главная с балансами счетов и вкладами инвесторов;
- журнал операций с расходами, доходами, переводами, долгами и заморозкой;
- быстрый ввод операции с категориями, объектами, контрагентами, НДС и вложениями;
- обзор по объектам: сумма тендера, потрачено, остаток, расходы по категориям и рабочие;
- настройки счетов, инвесторов, объектов, категорий и контрагентов;
- редактирование и архив операций для владельца;
- вход через Firebase Authentication;
- роли владельца и инвестора;
- Firestore-синхронизация данных;
- офлайн-очередь операций с автоматической отправкой после восстановления связи;
- экспорт и импорт JSON-бэкапа.

## Запуск

Откройте `index.html` в браузере.

Firebase-настройки находятся в `firebase-config.js`.

## Роли

- Владелец: полный доступ к операциям, настройкам, импорту и редактированию.
- Инвестор: видит данные и может добавлять операции, но не может редактировать, удалять и менять настройки.
