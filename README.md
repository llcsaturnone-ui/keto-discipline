# Keto Discipline PWA

Личное кето-приложение для iPhone: продукты, дневник еды, потенциальный приём пищи, дисциплина, прогресс и бэкап.

## Что внутри

- Ручная база продуктов с БЖУ на 100 г.
- Быстрое добавление еды: продукт + граммы.
- Потенциальный приём пищи / черновик: можно собрать тарелку и заранее увидеть итог дня.
- Авторасчёт ккал, белков, жиров и углеводов.
- Статус: кетоз вероятен / на грани / срыв.
- Вес, вода, шаги.
- Дисциплина 0–100%.
- История и график веса.
- Экспорт/импорт JSON.
- PWA: можно установить на iPhone через “На экран Домой”.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в него все файлы из этой папки: `index.html`, `app.webmanifest`, `sw.js`, папку `icons`.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Открой выданную ссылку GitHub Pages на iPhone.
7. В Safari нажми “Поделиться” → “На экран Домой”.

## Важно

Данные хранятся локально в браузере iPhone через `localStorage`. Перед очисткой Safari, сменой телефона или переустановкой приложения сделай экспорт JSON в настройках приложения.
